# Statistical Analysis of Afghan Nationals' Conviction Rates (2021–2023)

This project report analyzes conviction trends among Afghan nationals in the UK using Ministry of Justice data (2021–2023). It explores comparative conviction rates, statistical significance, and population-based rate ratios. The analysis highlights key disparities and provides insights into data-driven policy understanding.
